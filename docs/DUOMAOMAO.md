## 目前已经实现

2026-09-07 重做第一套美术素材，主题为「风铃岛」微缩小镇。

- 23 件独立场景部件和 8 个动物角色。
- 每个角色有命名的刚性部件层级和待机、走路、庆祝三段动画。
- 重新设计的平面小岛、道路、树屋、风车、房屋、集市、池塘与遮挡物布局。
- 导出 33 个可编辑 GLB（包含完整场景、角色合集）。
- 草地 PNG、5 段合成音效、新的图标和中文预览页面。
- 小镇、角色、道具预览；镜头、动作、光照和音效交互。
- 素材清单、文件哈希、生成脚本、源码压缩包和来源说明。
- 首页单人寻找模式：8 个可选角色、随机 5 位伙伴、3 分钟回合、移动、奔跑体力、镜头、碰撞、风铃提示、寻找判定、胜负结算与重开。
- 桌面键鼠和触屏摇杆；手动/切出窗口暂停；浏览器保存最快纪录。
- 可实际走通的户外地图、池塘边界和木桥，碰撞数据与美术布局一起生成。

当前页面不加载上游模型、纹理、字体、音频或提取的着色器。Vite / SvelteKit 的资源根目录改为 public，旧 reference 与 static 仅保留在开发工作区中。

## 当前玩法边界与后续

当前可玩的是单人寻找者模式。伙伴在开局随机选定的可达位置等待玩家找到；寻找判定包含距离和障碍遮挡。单人规则、操作和验证见 [SINGLE-PLAYER.md](./SINGLE-PLAYER.md)。

以下仍未实现：

1. 多人房间和服务端状态同步，包括两个浏览器看到彼此移动。
2. 玩家扮演躲藏者、电脑寻找者、物件伪装和多人身份分配。
3. 多人准备、躲藏、寻找、结算，以及掉线重连。
4. 跳跃、攀爬、树屋平台和建筑内部。当前建筑与楼梯按户外障碍处理。

`public/assets/world.json` 现在提供真实使用的碰撞轮廓和出生点；素材清单里的模型 bounds 不替代这些游戏碰撞数据，也不是联机服务端状态。

角色现阶段为刚性层级动画。若后续需要复杂动作、换装或自然肢体变形，需要进一步制作蒙皮骨架、权重和动作。

## 重新制作素材

修改 src/lib/duomaomao/assets 下对应参数和几何后，运行 pnpm assets:generate，然后运行 pnpm assets:check 和 pnpm build。生成器不会重新调用图像模型；草地 PNG 是已保存的图像，来源和原始提示词见 public/assets/PROVENANCE.md。
