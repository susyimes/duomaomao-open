# 风铃岛单人寻找模式

日期：2026-09-07。首页 `/` 为游戏，`/gallery` 为素材图鉴。

## 已实现

- 选择 8 种动物之一作为玩家。每局从其他动物中选 5 位，在可达的藏身点随机分布；伙伴不会自己换位置。
- 3 秒出发倒计时，随后有 180 秒寻找时间。找到 5 位即胜利，时间耗尽则结算失败；可以立即重开或回到小镇。
- 相对镜头的移动与奔跑、跟随镜头、转向和缩放。奔跑消耗体力，耗尽后恢复到一定体力才能再跑。
- 岛屿边界、水域、54 个圆形或旋转矩形障碍；移动分小步求解，靠近障碍可沿边缘移动。木桥允许跨过池塘并跟随桥面高度。
- 距离不超过 1.35 米且没有障碍挡住时才能找到伙伴；禁止穿墙寻找和重复计数。
- 3 次风铃提示，每次间隔 15 秒；持续 7 秒显示一处藏身位置，并给出区域文字。
- 小地图显示场景轮廓和玩家位置；伙伴只在靠近且视线无遮挡时显示，普通小地图不泄露藏身点。
- 手动暂停、切出窗口自动暂停；暂停时回合时间、移动和能力冷却冻结。
- 胜负结算、重新开始、返回大厅；当前浏览器保存最快通关用时、完成次数和声音设置。存储不可用时仍能游玩。
- 桌面键鼠和触屏摇杆。素材加载失败时显示重试入口；组件卸载会释放输入监听、动画循环、模型和音频资源。

## 实现与验证

`game/round.ts` 管理纯回合状态，`physics.ts` 处理碰撞和视线，`navigation.ts` 验证藏身点可达性。`input.ts` 收集键鼠/触屏输入；`view.ts` 渲染真实导出的 GLB，`runtime.ts` 连接时间、输入、音效和存储。

模型在游戏加载时按刚性节点合并同类彩色部件，保留动画枢轴；静态场景阴影只烘焙一次，角色使用地面影子。软件渲染器降低内部渲染分辨率并关闭阴影。此降级已在 Playwright Chromium 的 SwiftShader 环境验证，不代表所有实体手机或显卡的性能结果。

- `pnpm test`：地图可达性、100 个随机种子、穿墙/水域/桥面/边界、倒计时、体力、提示、寻找、暂停、胜负和重开；另验证合并模型后的几何边界、三角形数量与 8 个角色全部动作的形状/枢轴不变。包含 16 个游戏测试及 2 个上游示例测试。
- `pnpm test:play`：需保持 Vite 开发服务器运行。Playwright 使用真实键盘移动和 E 键寻找；仅读取状态规划路线，不传送、不改时间、不直接设置胜负。实测一局 81.49 秒找到 5/5，检查 418 个移动位置均未进入水域或障碍；验证胜利面板、纪录只保存一次、重开和返回大厅，无页面/控制台错误。
- 触屏实测：390×844，真实触摸事件验证选角、摇杆移动/奔跑、松手停止、拖动镜头后的相对方向、触摸取消、提示和暂停/继续。无水平溢出和页面/控制台错误。属于浏览器触屏模拟，未在实体手机上验证。
- 小屏布局复查：390 像素宽的大厅、320 像素宽的进度/小地图与触屏暂停面板均正常；进度面板与小地图不重叠，触屏暂停显示对应的操作说明。
- 正式构建实测：键盘移动、提示、暂停计时、刷新后声音设置仍在；实际等待回合倒计时结束，显示 0/5、03:00 的超时结算，未计入胜利纪录，再开一局正常。游戏与图鉴可来回切换；生产环境没有只读调试入口；旧参考资源返回 404，无外部网络请求或页面/控制台错误。
- 工程检查：`pnpm check` 为 0 错误、0 警告；修改的 Svelte 组件通过官方 autofixer；`pnpm test` 的 18 个测试通过；`pnpm assets:check`、`pnpm assets:validate`、`pnpm build` 通过。Three.js 客户端共享包仍有超过 500 kB 的构建提示，部署适配器尚未针对具体线上平台配置。

键盘报告和截图输出到 `.git/codex-validation/single-player/`，不进入应用和素材包。完整键盘脚本可用 `DUOMAOMAO_TEST_URL` 指定开发服务器。开发模式且 URL 带 `?debug` 时提供只读状态检查器；生产页面不提供该入口。

## 当前范围

这是户外、单人寻找者模式。没有多人服务器、玩家躲藏、电脑寻找者、物件变身、跳跃、攀爬或建筑内部。伙伴使用原创建模的刚性层级动画。没有执行线上发布。
