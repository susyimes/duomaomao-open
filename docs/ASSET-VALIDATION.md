# 原创素材验证记录

日期：2026-09-07。环境：Windows、Node.js 24.15.0、pnpm 11.7.0、Playwright Chromium。

## 1.1 版增量

单人游戏使用的木桥已延长，并增加与地图布局一起生成的 `world.json`（54 个障碍轮廓、出生点、水域、桥面）。清单由 40 增为 41 个条目；33 个 GLB 与 48 段动画的数量不变。当前 ZIP 的大小和哈希以生成文件及检查结果为准。单人玩法验证单独记录在 [SINGLE-PLAYER.md](./SINGLE-PLAYER.md)。

以下为 1.0 素材阶段的历史验证，大小和条目数对应当时的包。

## 素材与可编辑源码

- `pnpm assets:generate` 成功导出 33 个 GLB、5 个 WAV、1 张 PNG 和爪印 SVG。
- `pnpm assets:check` 验证通过：源文件指纹、文件哈希、GLB 结构、尺寸、动画名和压缩包内容一致。源码指纹规范化为 LF，兼容 Windows Git 换行设置。
- `pnpm assets:validate` 使用 GLTFLoader 重新加载全部 33 个 GLB。48 段导出动画均能移动实际节点，其中 24 段来自 8 个独立角色，其余 24 段是合集中的同一组动作。
- 将最终 ZIP 解压到独立验证目录，使用包内生成脚本重新生成；40 个素材条目的元数据与内容哈希完全一致。草地 PNG 复用包内文件，不重新调用图像生成。
- 浏览器实际下载的 ZIP 与工作区 ZIP 哈希一致，大小 3,617,822 字节。

## 浏览器

生产构建预览验证了小镇全景、8 个角色和全部 23 件独立场景部件。角色选择、待机/行走/庆祝、光照切换、声音开关、镜头控制和下载入口已操作。

桌面视口 1440×900；手机视口 390×844，三个视图均已截图检查，无水平溢出。测试期间无页面异常、控制台错误、原作素材请求或外部 HTTP 请求。

新生产输出不含 messenger、draco 或 reference 资源目录；旧模型/贴图路径返回 404。验证中发现上游 SvelteKit 预览版本在根错误路由进行 SSR 时会抛出缺失组件错误，已将原有客户端渲染选项移至根 layout，使缺失资源正常返回 404。
